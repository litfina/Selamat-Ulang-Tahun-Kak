# Cara Menambahkan Lagu

## Langkah-langkah:

1. **Copy file lagu** ke folder ini: `src/data/songs/`
2. **Ganti nama file** menjadi `birthday-song.mp3` (atau format audio lain yang didukung)
3. **Import di aplikasi** - File sudah di-import di komponen AudioPlayer

## Format yang didukung:
- `.mp3` (rekomendasi)
- `.wav`
- `.ogg`
- `.m4a`

## Tips:
- Pilih lagu yang romantis dan bermakna
- Ukuran file sebaiknya tidak lebih dari 10MB untuk performa optimal
- Lagu akan diputar otomatis saat pengguna membuka kado
